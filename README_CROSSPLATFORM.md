# Collabs Retouch Pro - Cross-Platform Native Suite

Geen browser-onzin, geen trage webpagina's. Dit is een volwaardige, native desktop-applicatie gebouwd met professionele GUI-frameworks en high-performance Python image processing (Pillow, InsightFace & High Pass / Frequency Separation pipelines).

## Bestanden & Launchers per OS

1. **macOS (.app Bundle & Command Launcher)**
   - App Bundle: `/home/dave/Applications/Collabs Retouch Pro.app`
   - Terminal Command Launcher: `/home/dave/Applications/Collabs Retouch Pro/launch.command`
   - Installatie / Rebuild script: `python3 make_macos_app.py`

2. **Linux (.sh Launcher & Native Desktop Integration)**
   - Shell Launcher: `/home/dave/Applications/Collabs Retouch Pro/launch.sh`
   - Uitvoeren: `cd "/home/dave/Applications/Collabs Retouch Pro" && ./launch.sh`

3. **Windows (.bat Batch Launcher)**
   - Batch Launcher: `/home/dave/Applications/Collabs Retouch Pro/launch.bat`
   - Klik of voer uit via Command Prompt of Explorer.

## Kenmerken & Engines
- **Retouch Pane:** Frequency Separation (High Pass 2.5), Skin Smoothing & Tone Balance, Dodge & Burn Enhancer.
- **Color Grading:** Exposure, Contrast, and Saturation sliders with live image preview.
- **AI Engines:** InsightFace 128 + IPAdapter Face Fidelity Boost, AI Super-Resolution 2x/4x Upscale.
